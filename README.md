# LoopRush 🎮
A fast-paced viral Android arcade game built for thrill-seekers and casual gamers. Race through endless loops, dodge obstacles, and climb the global leaderboard in this addictive challenge.

---

## 🚀 Features
- ⚡ Smooth Android gameplay optimized for all devices
- 🏆 Competitive scoring system with leaderboards
- 📦 Lightweight APK for quick download and install
- 🎉 Free to play, open for community contributions

---

## 📥 Installation
1. Download the latest `LoopRush-Android.apk` from the [Releases](./releases) section.
2. Transfer the APK to your Android device.
3. Enable **Install from Unknown Sources** in your device settings.
4. Tap the APK to install and start playing!

---

## 🎯 Gameplay
- Tap to jump through loops and avoid obstacles.
- Collect points and bonuses to boost your score.
- Challenge friends or climb the global leaderboard.
