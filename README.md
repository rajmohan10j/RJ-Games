## 🕹️ Featured Games

### ⚡ [Neon Breakers: Cyber Hero vs Villains 3D](./Neon-Breakers)
A 3D endless action runner and shooter game built with **Three.js** and **Vite**.
- **Hero vs. Villains Combat:** Control an animated 3D Cyber Hero firing dual plasma blasters to destroy 3D Mecha-Goblin monsters and hovering drones.
- **Cross-Platform:** Full PC keyboard/mouse and mobile touch action buttons (`🦘 JUMP` & `🔥 BLAST`) with adaptive portrait camera framing.
- **Procedural Sound FX & Particles:** Explosions, lasers, and energy crystals.
- **Directory:** [`/Neon-Breakers`](./Neon-Breakers)

---

## 🚀 How to Run Neon Breakers Locally

```bash
cd Neon-Breakers
npm install
npm run dev
```

Open **http://localhost:5173** in your browser.
